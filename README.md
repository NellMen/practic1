# НЕ ФОРМА

Адаптивная главная страница концептуального бренда дизайнерского освещения на React и CSS.

## Запуск

```sh
npm install
npm run dev
```

Для production-сборки выполните `npm run build`.

Страница разбита на секции-компоненты в `src/App.jsx`; стили приложения ограничены пространством имён `.home-page` в `src/App.css`.
